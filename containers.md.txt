containers.md
Overview

Containers are objects placed on the main Garden Board.
Plants cannot be placed directly on the board — they must be placed inside containers.

Containers define:

How many plants can be placed
What bonuses plants receive
What combinations are possible
How adjacency works
What recipes are allowed

Containers are one of the main sources of strategy.

Container Properties

Each container has:

name
size (grid size on board)
capacity (plant slots)
soil type
affinity (optional)
shape
rarity
special rules

Example:

name: Wooden Planter
size: 2x1
capacity: 2
soil: normal
affinity: none
rarity: common
rules: none
Size

Size determines how much space the container takes on the Garden Board.

Examples:

Size	Tiles
1×1	1
2×1	2
2×2	4
3×2	6
3×3	9
1×3	3
4×2	8

Containers cannot overlap.

Capacity

Capacity determines how many plant slots exist inside.

Capacity may be less than size.

Examples:

Container	Size	Capacity
Clay Pot	1×1	1
Planter	2×1	2
Bed	3×2	6
Basin	2×2	2
Rune Circle	2×2	3
Ancient Bed	3×3	9
Soil Types

Soil type affects plant behavior.

Soil	Effect
normal	no bonus
rich	faster triggers
dry	thorn bonus
damp	fungus bonus
sacred	spirit bonus
cursed	rot bonus
radiant	sun bonus
lunar	moon bonus

Plants matching soil get bonus power.

Affinity

Some containers have element affinity.

Affinity gives bonus to plants of that element.

Example:

Rune Circle
affinity: Spirit

Stone Basin
affinity: Water

Sun Bed
affinity: Sun

Shape Rules

Shape may affect adjacency.

Possible rules:

wide containers boost neighbors
tall containers boost vertical
square containers boost same container plants
circle containers boost spirits

Shape rules are optional.

Container Rules

Containers may have special rules.

Examples:

bonus if full
bonus if same element
bonus if mixed elements
bonus if rare plants
bonus if adjacent container
bonus if relic nearby

Container-Based Recipes

Some recipes require container type.

Examples:

Spirit Fern + Rune Circle → Grove Spirit

3 Rotroot in Rot Pit → Rot Mass

Full Bed of Flowers → Flower Spirit

Moon plants in Lunar Planter → Lunar Bloom
Adjacency Rules

Containers may affect neighbors.

Possible effects:

same soil bonus
same element bonus
relic range
aura containers
ritual containers

Example:

Rune Circle boosts containers touching it.
